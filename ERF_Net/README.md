# ERFNet component

This directory contains the ERFNet training/evaluation snapshot used by this repository. For the repository overview, dataset restrictions, legacy environment notes, checkpoint provenance, result interpretation, and the relationship to the broader private research workspace, see the [root README](../README.md).

The upstream [ERFNet project](https://github.com/eromera/erfnet) states that its work is licensed under CC BY-NC 4.0. This repository also contains locally produced checkpoints and experiment artifacts whose individual provenance and redistribution permissions have not all been independently verified. Review the root README before sharing them.

The original code targets legacy Python/PyTorch/CUDA versions. No current-runtime compatibility or independent reproduction of the stored metrics is claimed.
